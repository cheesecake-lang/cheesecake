description: Display CheeseCake help and documentation

# Usage

```
/cheesecake help [topic]
```

# Topics

- `agents` - Defining agents
- `skills` - Defining skills
- `control-flow` - IF, LOOP, PARALLEL
- `functions` - Creating functions
- `examples` - See examples

# Output

Shows relevant documentation from syntax-reference.md based on topic.

Default (no topic):
```
🧀 CheeseCake Help

Quick Start:
  1. Create workflow: /cheesecake create
  2. Run workflow: /cheesecake run <file>
  3. Get help on topic: /cheesecake help <topic>

Available topics:
  • agents, skills, variables
  • control-flow, loops, parallel
  • functions, modules
  • examples, syntax

Full docs: See skills/cheesecake/syntax-reference.md
```
