# Contributing to CheeseCake

Thank you for your interest in contributing to CheeseCake! 🧀

## How to Contribute

### Reporting Issues

- Use GitHub Issues to report bugs or suggest features
- Include `.cheesecake` file examples when relevant
- Describe expected vs actual behavior

### Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Make your changes
4. Test your changes with example workflows
5. Commit with clear messages
6. Push and create a Pull Request

### Code Style

- Add comments explaining non-obvious logic
- Follow existing code structure
- Update documentation for new features

### Adding Examples

New `.cheesecake` examples are always welcome!
- Place in `templates/` or `examples/` directory
- Include clear comments explaining what it does
- Test before submitting

## Development Setup

```bash
# Clone the repo
git clone https://github.com/cheesecake-lang/cheesecake.git
cd cheesecake

# Install as Claude Code plugin
# (In Claude Code)
/plugin install /path/to/cheesecake

# Test
/cheesecake run templates/hello-world.cheesecake
```
